> - 응답자는 LLM이 연기한 합성 퍼소나이고, 각 판단의 '숨은 실제 이유'도 LLM이 만들었다.

## 1. 목적과 결론 요약
논문 가설은 다음과 같다. 행동-지식 간극을 겨냥한 질문과 예상 답을 확인·교정(A)하면, 이유를 직접 서술(B)하는 것보다 빠르고 비슷한 정확도로 암묵지를 끌어낸다. 이 시뮬레이션은 '빠르기'가 아니라 **예상 답의 적중률, 앵커링, A·B의 정확도·구체성**을 봤다.

| 사전 등록 지표·가설 | 결과 | 판정 |
|---|---|---|
| M1 예상 답 적중률 | 엄격 47%, 느슨 64% | 기술 통계(예상 답 3개 중 하나라도 맞는 경우가 절반 안팎) |
| H-anchor: 앵커링 > 0, rushed > normal | normal 36% → rushed 52% (적중 없는 항목 87개 기준). 퍼소나 단위 +0.18 [0.01, 0.34], 부호 검정 p = 0.18 | 앵커링 > 0은 지지. rushed 증가는 방향만 맞고 **유의하지 않음** |
| H-acc: A ≈ B (차이가 ±0.3 안) | A 1.23 vs B 1.98 (normal), 차이 −0.75 [−0.88, −0.62] | **기각: B가 더 정확** |
| H-spec: B > A (판단 규칙 수) | A 1.49 vs B 1.80, p < 0.001 (rushed 1.40 vs 1.60, p = 0.006) | 지지 |
| M5 입력량 | 직접 입력한 글자 수: A 30자 vs B 129자 (rushed 17 vs 83) | A가 1/4 수준 |

**한 문장 결론:** 예상 답은 절반 정도만 숨은 이유를 맞혔다. 응답자는 틀린 예상 답도 자주 그대로 받아들였고(특히 바쁠 때), 결과적으로 A는 B보다 입력이 훨씬 적은 대신 숨은 이유를 덜 담았다. 저자 1인 파일럿에서 본 '빠르지만 예상 답에 끌려갈 위험'이 시뮬레이션에서는 정확도 손실로 크게 나타났다.

### 절차
1. **판단 생성(P)**: 퍼소나 프로필을 보고 반복 업무 판단 12개(관찰 행동 문장)와 각각의 숨은 실제 이유를 만든다. 숨은 이유는 Q에게 보이지 않는다.
2. **배정**: 퍼소나 × 팔마다 무작위 6A / 6B.
3. **질문 생성(Q)**: A 항목의 행동 문장과 직무만 보고, 간극 겨냥 질문 1개와 예상 이유 3개(각 40자 이내)를 만든다.
4. **응답(P, 새 세션)**: 퍼소나 역할을 맡고, 숨은 이유를 '기억'으로 받는다.
   - A: 맞는 예상 이유를 선택(복수 가능), '모두 틀림', 자유 교정
   - B: 이유를 직접 서술
   - 변형: normal과 rushed("바쁘니 대충 빨리").
5. **채점(J 두 명, 조건 모름)**:
   - 정확도 0–2: 최종 답이 숨은 이유의 핵심 기준을 담았는가
   - 구체성: 판단 규칙 수
   - 예상 이유 3개 각각이 숨은 이유와 일치하는가
   - 주 점수는 두 채점자의 평균이다.
- **분석**: 퍼소나 단위 대응 비교(윌콕슨, 부호 검정), 퍼소나 재표집 부트스트랩 5,000회.

## 4. 해석
1. **예상 답은 절반 정도만 맞았다.**
   - 엄격 기준 47%, 느슨 기준 64%다. 질문 생성기(Q)가 claude일 때(팔 2) 적중률이 더 높았다(엄격 54% vs 39%).
   - 맞은 경우에도 예상 답은 대개 일반론이었다. 예: 숨은 이유가 "기구가 1cm 어긋난 조에서 비커가 쏟아진 적이 있어 직접 잰다"일 때, 예상 답은 "안전사고를 줄이려고"였다. 그래서 예상 답만 고르면 정확도가 1점(일부)에 머물렀다. A의 정확도가 적중 여부와 거의 관계없이 1.0–1.3에 머문 이유다.
2. **앵커링이 흔했고, 바쁠 때 늘었다.**
   - 적중 없는 항목에서 틀린 예상 답을 '모두 틀림'이나 교정 없이 받아들인 비율은 normal 36%, rushed 52%였다.
   - 교정 여부와 무관하게 틀린 보기를 고른 비율은 77–79%였다(탐색 지표).
   - 응답자 모델에 따라 차이가 컸다. P = claude는 48% → 68%, P = gpt-luna는 13% → 23%였다. 어떤 응답자 모델을 쓰느냐가 결과를 크게 좌우한다.
   - rushed 증가는 퍼소나 단위 부트스트랩 CI가 0을 겨우 넘지만(+0.18 [0.01, 0.34]), 사전 등록한 부호 검정은 유의하지 않았다(p = 0.18).
3. **A는 입력이 1/4이지만 덜 정확하고 덜 구체적이었다.** 직접 입력한 글자 수는 A 30자 vs B 129자였다. 정확도는 A 1.23 vs B 1.98, 판단 규칙 수는 1.49 vs 1.80이었다. 이 결과는 두 팔과 두 채점자 모두에서 같은 방향이다.
4. **채점 신뢰도**: 정확도 점수의 가중 κ는 0.85, 예상 답 적중 판정의 κ는 0.72다. 두 채점자(claude-sonnet, gemini-4-argon) 각각으로 봐도 결론이 같다.

## 5. 한계
- **사람이 아니다.** 응답자 P는 숨은 이유를 문자 그대로 '기억'으로 받는다. 그래서 B에서는 그 이유를 거의 그대로 옮겨 적을 수 있다(B 정확도 1.98 ≈ 천장). 사람은 자기 판단의 이유를 이렇게 완전히 떠올리지 못하므로, B의 실제 정확도는 이보다 낮을 수 있다. 저자 파일럿의 본인 평정에서 B는 4.5/5였다. 따라서 A−B 정확도 차이는 사람에서 과장됐을 가능성이 크다.
- **시간을 재지 않았다.** LLM 지연은 사람의 소요 시간과 무관하다. A의 이점인 '빠르기'는 이 시뮬레이션으로 평가하지 않았다. 입력 글자 수만 노력의 대리 지표로 썼다.
- **숨은 이유도 LLM이 만든 것이다.** 일부 생성기(gpt-6-luna)는 숨은 이유를 "아마…", "가설:…"처럼 추정 투로 썼다.
- **채점자가 같은 계열인 경우가 있다.** 채점자 claude-sonnet은 팔 1의 응답자, 팔 2의 질문 생성기와 같은 계열이다. 이를 점검하려고 두 채점자를 따로 보고했다.
- **표본과 모델 변경.** 계획한 30명이 아니라 20명이고, 실행 중 모델을 바꿨다(사전 등록 변경 기록).
- **'반복 판단'은 LLM이 구성한 장면이다.** 실제 행동 기록에서 온 간극이 아니다.

## 6. 논문 삽입용 초안

**본문(3–4문장)**
> 사람 데이터를 보완하기 위해, 한국어 합성 퍼소나 20명(NVIDIA Nemotron-Personas-Korea)을 LLM이 연기하는 셀프 설문 시뮬레이션을 사전 등록 후 수행했다. 퍼소나별 반복 업무 판단 12개와 숨은 이유를 만들고, 다른 계열 모델이 판단 문장만 보고 만든 예상 답 3개를 확인·교정(A)하거나 이유를 직접 서술(B)하게 했다. 예상 답은 47%(엄격 기준)만 숨은 이유와 일치했고, 일치하지 않을 때도 '모두 틀림'이나 교정 없이 받아들인 비율이 36%였으며 바쁜 상황 지시에서는 52%로 늘었다. A는 직접 입력한 글자 수가 B의 약 4분의 1이었지만, 숨은 이유를 담은 정도는 낮았다(0–2점 기준 1.23 대 1.98). 이는 LLM 응답자에 대한 결과로 사람 증거가 아니지만, 예상 답 밖의 기준을 말하게 하는 장치가 필수라는 설계 원칙을 뒷받침한다.
