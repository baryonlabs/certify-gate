# 사전 등록: 합성 한국어 퍼소나 셀프 설문 시뮬레이션

작성 2026-11-23 03:35 KST. 퍼소나 샘플링과 LLM 호출을 실행하기 **전에** 이 문서를 커밋한다. 이후 변경은 맨 아래 '변경 기록'에만 추가한다.

> 이 시뮬레이션은 LLM이 연기한 합성 퍼소나의 응답이다. **사람에 대한 증거가 아니다.** '숨은 실제 이유'도 LLM이 만든 것이다.

## 배경
논문 가설은 다음과 같다. 행동-지식 간극을 겨냥한 질문과 예상 답을 사람이 확인·교정(A)하면, 이유를 직접 서술(B)하는 것보다 빠르고 비슷한 정확도로 암묵지를 끌어낸다. 저자 1인 파일럿(16건)에서 A는 약 2.5배 빨랐지만 '모두 틀림'이 한 번도 선택되지 않아 앵커링 위험이 드러났다. 이 시뮬레이션은 세 가지를 본다.
1. 예상 답이 숨은 이유를 얼마나 맞히는가
2. 틀린 예상 답을 그대로 받아들이는가
3. A와 B의 정확도·구체성 차이

## 퍼소나
- 출처: NVIDIA Nemotron-Personas-Korea (CC BY 4.0). HF datasets-server API로 조회한다.
- 표본: 고정 시드(20261123)로 고른 무작위 오프셋의 행 중에서 뽑는다.
  - 조건: 25–64세이며, 반복 판단이 있는 직무군(사무, 연구, 제조·생산, 의료, 교육, 영업·판매, IT)에 속하는 직업.
  - 직무군·지역·성별이 고르게 섞이도록 30명을 고른다.
  - 비용·시간 한도로 못 끝내면 같은 순서의 앞에서부터 최소 12명까지 줄이고 기록한다.

## 모델 조합 (두 팔, 모든 퍼소나가 두 팔 모두에 참여)
- 팔 1: P = claude-haiku (판단·숨은 이유 생성, 응답), Q = codex/gpt (질문·예상 답 생성)
- 팔 2: P = codex/gpt, Q = claude-haiku
- J(채점): 세 번째 계열 gemini CLI는 클라이언트 지원 종료로 쓸 수 없다. 그래서 claude-sonnet과 codex/gpt가 **모든 기록을 각각 채점**한다.
  - 주 점수는 두 채점자의 평균이다.
  - 두 채점자의 일치도(가중 κ 또는 단순 일치율)를 보고한다.
  - 채점자는 조건(A/B)·팔·변형을 모른다. 답은 순수 텍스트로 바꾸고 섞어서 제시한다.

## 절차
1. **판단 생성(P)**: 퍼소나 프로필을 보고, 이 사람이 최근 반복적으로 내리는 업무 판단 12개와 각각의 '숨은 실제 이유'를 만든다. 숨은 이유는 구체적 판단 기준이며 문서화되지 않은 것이다. 숨은 이유는 별도 파일에 저장하고 Q에는 절대 주지 않는다.
2. **배정**: 퍼소나 × 팔마다 무작위 6A / 6B (시드 고정).
3. **질문 생성(Q)**: A 항목마다 판단 문장과 직무만 보고, 간극을 겨냥한 질문 1개와 예상 이유 3개(각 40자 이내)를 만든다. 퍼소나 단위로 묶어 한 번에 호출한다.
4. **응답(P, 새 세션)**: 퍼소나 역할을 맡기고 자신의 숨은 이유를 '기억'으로 준다. 블록은 퍼소나 × 팔 × 변형 × 조건마다 1회 호출한다.
   - A: 예상 이유 중 맞는 것 선택(복수 가능), '모두 틀림', 자유 교정 입력
   - B: 이유를 직접 서술
   - 변형: normal, rushed. rushed에는 "바빠서 대충 빨리 답하라"는 압박을 넣는다(사람의 노력 제한 대리).
5. **채점(J, 조건 모름)**:
   - 최종 답(A는 고른 이유 + 교정, B는 서술)이 숨은 이유를 담았는지: 0 없음, 1 일부, 2 핵심 포함
   - 구체성: 답에 든 서로 다른 판단 규칙의 수
   - A의 예상 이유 3개 각각이 숨은 이유와 일치하는지(적중)

## 지표와 가설
- **M1 예상 답 적중률**: A 항목 중 예상 이유 3개 중 하나라도 숨은 이유와 일치하는 비율(J 두 명이 모두 일치로 본 경우를 엄격 기준, 한 명 이상이면 느슨 기준). 기술 통계만 낸다.
- **M2 앵커링 비율**: 적중 없는 A 항목 중, '모두 틀림'도 교정 입력도 없이 예상 이유를 하나 이상 고른 비율.
  - **H-anchor**: M2 > 0이고, rushed의 M2가 normal보다 크다. 퍼소나 단위 대응 부호 검정, 양측.
- **M3 정확도(0–2)**: A vs B.
  - **H-acc**: 퍼소나 단위 평균 차이(A − B)의 95% 부트스트랩 CI가 ±0.3 안이면 '비슷함'으로 판정한다(동등성 여유 0.3, 사전 지정).
  - 차이 검정: 윌콕슨 부호 순위, 양측.
- **M4 구체성(규칙 수)**: **H-spec**: B > A. 윌콕슨, 양측.
- **M5 출력 길이**: 사람이 실제로 입력한 글자 수(A는 교정 입력, B는 서술)와 최종 답 전체 길이. 기술 통계, rushed 변화.
- **M6 rushed 효과**: 정확도·구체성·길이의 normal − rushed 차이를 조건별로 본다.
- **분석 단위**: 퍼소나다. 각 팔 × 변형 안에서 퍼소나별 평균을 내고 대응 비교한다.
  - 주 결과는 두 팔을 합친 퍼소나별 평균이다(퍼소나당 A·B 각 6항목 × 2팔).
  - 팔별 결과를 함께 보고한다.
  - 부트스트랩은 퍼소나 재표집 5,000회다.
- **결측**: JSON 해석 실패는 1회 재시도한다. 그래도 실패하면 해당 블록을 제외하고 개수를 보고한다.

## 해석상 한계 (사전 명시)
- 응답자와 숨은 이유 생성자가 같은 모델 P다. 그래서 P는 '정답'을 알고 응답하므로 사람보다 정확도가 높게 나올 수 있다. 정확도 비교는 형식(A/B)이 기억된 이유를 얼마나 손실 없이 전달하는지에 가깝다.
- 시간은 LLM 지연이라 측정하지 않는다. A가 빠른가는 이 시뮬레이션으로 답하지 않는다.
- 채점자 2명 중 하나는 각 팔의 P 또는 Q와 같은 계열이다(자기 계열 편향 가능). 그래서 두 채점자를 따로 보고한다.
