# 저자 1인 파일럿 (논문 4장 표 3·4)

> **탐색적 관찰**이다. 참여자는 설계자 본인 1명이고, 정확도는 본인 평정(독립 평가 아님)이다. 일반화할 수 없다.

- **행동 16건**: 저자가 연구 에이전트와 루프를 구축하며 논문을 준비한 이틀 동안 에이전트에 내린 지시·결정 가운데, 에이전트가 기록에서 온톨로지가 이유를 설명하지 못하는 16건을 골랐다(선정은 수작업, 간극 판정 정밀도는 측정하지 않음).
- **배정**: 번갈아 8건씩. (A) 간극 겨냥 질문 + 예상 답 3개를 보고 고르거나 고침('모두 틀림'·자유 입력 가능). (B) 질문 없이 이유를 직접 적음.
- 예상 답은 연구 에이전트(Claude 계열 LLM)가 논문 3장 ④의 방식으로 만들었다(생성 방식: [`tools/expected-answers/`](../../tools/expected-answers/)).
- 시간은 항목마다 '시작'을 누른 때부터 제출까지 잰다.

## 파일
- `items.json`: 항목 16개 정의(행동 문장, A 항목의 질문과 예상 답 3개). 원본은 파일럿 화면(`tacit_pilot.html`)의 `ITEMS`.
- `responses.json`: 응답 16건(시간 ms, 고른 예상 답, 입력 텍스트, 본인 평정 1–5, 제출 시각). 원본 `t01..t16.json`을 합친 것.
- `analyze.mjs`: 분석(의존성 없음) → `summary.json`.
- **개인정보**: 응답자는 저자 본인이며, 내용은 저자 본인의 연구 작업 지시와 그 이유뿐이다. 제3자 정보·연락처는 없다.
