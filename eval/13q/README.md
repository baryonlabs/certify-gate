# 13문항 제3자 평가 (논문 5장 · 각주 2)

> 소규모 탐색 평가다. 채점자는 LLM이고, 그중 2개는 연구 에이전트와 같은 Claude 계열이다.

지식 저장소를 보지 않은 별도 에이전트가 공개 문헌에서 질문 13개와 참조 답을 만들고(`questions.json`), 오프라인 로컬 LLM **Qwen3.5-27B**(vLLM, 사고 모드 끔, 문맥 32K)에 네 조건으로 물었다.

| 조건 | 설명 | 답변 파일 |
|---|---|---|
| (가) 검색 끔 | `use_retrieval=false` | `answers.json` (`cond=baseline`) |
| (나) 원문 18건 검색 | 루프가 참조한 1차 출처 원문 검색(단어 일치) | `answers_rag.json` |
| (다) 원문 300자 조각 검색 | 같은 원문을 300자 조각으로 나눠 검색 | `answers_rag_small.json` |
| (라) 루프 온톨로지 검색 | 루프가 쌓은 온톨로지 검색(Baryon AX) | `answers.json` (`cond=loop`) |

## 채점
- 응답 52개(13 × 4)를 조건을 가린 LLM 채점자가 `correct / partial / refusal / incorrect`와 '지어냄(fabrication)'으로 판정했다(`judge_items_all.json`은 채점자에게 준 입력).
- `judges/judge_{,rag_,small_}A.json`, `…B.json`: Claude 계열 채점자 2개(서로 완전 일치, κ = 1.00). `judges/judge_C.json`: GPT 계열 교차 채점(52개 전체). Claude–GPT 교차 κ = **0.83**(일치 92%, 불일치 4건).
- 주 라벨은 Claude 계열 두 채점자의 합의다. '실질적 답' = 정답 + 부분 정답.

## Q01 재판정
- Q01의 참조 답은 **NBER 워킹페이퍼 w31161 판본**(상담원 5,179명, 평균 14%, 초보·저숙련 34%)이었다. 그래서 루프(라)의 답 '평균 15%, 상담원 5,172명'은 처음에 세 채점자 모두 **오답·지어냄**으로 판정했다.
- 저자가 1차 출처를 확인한 결과 15%·5,172명은 **QJE 2025 출판본**(140(2)) 수치였다. 지어낸 수치가 아니므로 **부분 정답**으로 고쳤다(34% 누락, 그리고 워킹페이퍼 수치 14%를 보도한 MIT Sloan 기사를 출처로 달아 판본이 어긋남). 근거와 내용은 `rejudge.json`.
- 이 사례가 논문 5장의 요지다. 에이전트의 '확인'은 판본까지 보장하지 않으므로 사람이 원문과 대조하는 절차가 필요하다.

## 파일
- `questions.json`: 질문·참조 답·핵심 사실·출처 URL
- `answers*.json`: 조건별 답(`blind_id`로 채점과 연결)
- `judges/`: 채점 결과, `judge_items_all.json`: 채점 입력
- `rejudge.json`: 재판정 기록
- `rag_urls.txt`: (나)·(다)에 쓴 1차 출처 URL 25개와 수집 본문 길이. **원문 텍스트는 저작권 때문에 공개하지 않는다**(본문 확보 18건).
- `run_eval.py`: (가)·(라) 실행 스크립트. 내부 접속 경로(SSH 호스트·내부 IP)와 권한 헤더를 지우고 환경 변수(`BARYON_AX_URL`, `BARYON_AX_HEADERS`)로 바꿨다. (나)·(다) 실행 스크립트는 보존되지 않았다.
- `analyze.py`: 채점자 일치·조건별 집계·재판정 반영·맥니마 정확검정.

## 한계
제3자 질문 13개, 응답 모델 1개, 채점자도 LLM이다. 검색은 단어 일치 방식이다. 참조 답 자체가 한 판본에 묶여 있었던 것처럼, 참조 답의 오류가 판정에 그대로 들어갈 수 있다.
